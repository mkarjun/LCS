# Planning Workspace

This folder keeps delivery trackers, service packs, and execution templates out of the repo root.

- `master-checklist.md` is the cross-repo delivery tracker.
- `services/` holds one scenario pack per service.
- `aws-console-parity.md` defines the visual and behavioral acceptance bar for AWS console matching.
- Every service pack owns 30 business scenarios scoped to that service.
- Cross-service flows belong to the primary service pack and must name dependent services in evidence or notes.
- Console work is only complete when UX and behavior match AWS as closely as practical while using LCS branding.
