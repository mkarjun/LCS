- Service: S3
- Phase: 2
- Protocol: REST XML
- Owner wave: Object storage

## API Parity

- [ ] Bucket CRUD matches AWS REST XML behavior.
- [ ] Object CRUD matches AWS REST XML behavior.
- [ ] Location constraint, region handling, and virtual-host or path-host behavior are validated.
- [ ] Error XML, status codes, and request IDs match AWS expectations.
- [ ] Listing, pagination, signing, and pre-signed URL behavior are validated.

## Console Parity

- [ ] Bucket inventory matches AWS S3 console layout, labels, and table behavior.
- [ ] Bucket detail navigation matches AWS S3 console information architecture.
- [ ] Object browser matches AWS upload, download, and delete flow behavior.
- [ ] Create-bucket flow matches AWS region-selection and validation behavior.
- [ ] Empty states, breadcrumbs, and destructive confirmations match AWS UX closely.
