## API Parity

- [ ] Request parsing matches AWS wire shape.
- [ ] Response body matches AWS field presence and naming.
- [ ] Error codes and XML or JSON envelopes match AWS expectations.
- [ ] Pagination, filtering, idempotency, and retries behave correctly.
- [ ] Region and account scoping behave correctly.

## Console Parity

- [ ] Inventory and detail surfaces match AWS information architecture for this service.
- [ ] Layout density, spacing, labels, icons, and table behavior match AWS closely.
- [ ] Create, update, and destructive flows match AWS interaction order and copy closely.
- [ ] Validation, empty states, loading states, and error states match AWS behavior closely.
- [ ] Navigation, breadcrumbs, side rails, and entry points stay AWS-like while using LCS branding.
